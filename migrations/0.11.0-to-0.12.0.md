# Migration 0.11.0 to 0.12.0

Version 0.12.0 finishes the lean hq started in 0.11.0:

- **One folder per initiative.** Work that spans several sessions or departments gets its own folder, `initiatives/<slug>/`, with a one-page `status.md` (goal, state, next step, links to documents and decision records) that only the chief of staff edits. Departments write their documents for it into that folder and name it in their handoff. On close the chief of staff writes a short summary and, with the CEO's OK, moves the folder to `archive/`. Work that one department finishes in one go stays in `departments/<id>/`. A new hidden skill, `initiatives`, holds the steps.
- **One-line indexes.** Every folder of documents gets a `README.md` with one line per document, kept by whoever writes there. Agents read the index first and open only the document they need.
- **Hygiene in the weekly brief.** The brief gains a fixed step that lists files over their size budget, current documents whose `as_of` is more than 90 days old, pending items open for more than 14 days and idle initiatives, and checks for contradictions, stale claims, orphan documents and missing cross-references. It proposes what to archive; nothing is archived without the CEO's OK.

Nothing new is read at session start: indexes and initiative pages are read when the work needs them.

No schema changes: `org.yaml` stays `org/5` and `company/state.md` stays `state/1` (an open initiative uses the existing "Products and status" line format, pointing to its `status.md`). Handoff notes gain one optional frontmatter field, `initiative`.

Apply the sections below in order. In the hq the template placeholders are already rendered, so each edit names a fragment without placeholders, or says which value of this hq to use. Where a fragment is not found exactly (the CEO edited that part), do not guess: show the CEO the current text and the intended result, and ask.
