# Migration 0.8.0 to 0.8.1

Version 0.8.1 makes one change, in the plugin only:

- One supported install: one copy of the plugin at project scope, in the hq folder. The plugin could end up installed twice on one computer, at user scope (the earlier README steps) and at project scope (the hq's `.claude/settings.json`, where `init-fleet` writes `enabledPlugins`). Updating one copy left the other on an older version, and a session could load the older one. The README install and update steps now use project scope and say how to check for and remove a second copy. When the hq is newer than the loaded plugin, `hq-version` now says that a second, older install at another scope may be the one loaded.

No schema changes: `org.yaml` stays `org/4`, `company/state.md` stays `state/1`. No hq file changes apart from the version. The hq's `.claude/settings.json` keeps its `enabledPlugins` entry as it is.
