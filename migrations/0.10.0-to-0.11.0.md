# Migration 0.10.0 to 0.11.0

Version 0.11.0 changes:

- **A leaner hq.** The start-of-session routine, the department and grant steps, and the product repos procedures move from `CLAUDE.md` into hidden plugin skills loaded on demand (`session-start`, `departments`, `product-repos`). The files read at every session start get a size budget, checked at session start. Analyses and notes get lifecycle frontmatter, and an `archive/` folder that default searches skip.

Apply the sections below in order. In the hq the template placeholders are already rendered, so each edit names a fragment without placeholders, or says which value of this hq to use. Where a fragment is not found exactly (the CEO edited that part), do not guess: show the CEO the current text and the intended result, and ask.

## Version

`org.yaml`: `framework_version: 0.10.0` becomes `framework_version: 0.11.0`.

`company/state.md`: frontmatter `framework_version: 0.10.0` becomes `framework_version: 0.11.0`.
