# Initiatives

One folder per piece of work that spans several sessions or departments: `initiatives/<slug>/`, with a one-page `status.md` (goal, state, next step, links) and a `README.md` index of its documents. The chief of staff opens, updates and closes initiatives; only the chief of staff edits a `status.md`. Work that one department finishes in one go stays in `departments/<id>/`.

Read this list first and open only the initiative you need. One line per initiative: `- [<slug>](<slug>/status.md): <goal in a few words>; <state>, updated YYYY-MM-DD`. A closed initiative moves to `archive/initiatives/<slug>/` with the CEO's OK, and its line moves to "Archived".
