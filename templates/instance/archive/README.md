# Archive

Documents that are no longer current, kept for history. Each one keeps the path it had (for example `archive/departments/<id>/<file>`) and has `status: archived` in its frontmatter (see "Documents" in `CLAUDE.md`).

`.ignore` at the hq root keeps this folder out of default searches, so old material does not crowd out current material. To search it, name `archive/` as the path. Git still tracks it.

Archive only when the CEO asks or agrees; moving a document here is an hq commit.
